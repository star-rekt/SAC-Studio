SAC Studio setup

Your campaigns stay in your own computer account. Claude and Figma use your own sign-ins; no credentials are included in this installer.

1. Claude Code

Install Claude Code, open a terminal, run claude, and sign in with your own account.

2. Figma plugin

In Figma Desktop, choose Plugins → Development → Import plugin from manifest and select the included manifest. Figma sign-in remains yours.

3. Fonts and image export

Install your organisation’s licensed Quiet Sans and Sofia Pro faces for matching typography. A local Chrome or Edge installation is needed for screenshot/export features.
